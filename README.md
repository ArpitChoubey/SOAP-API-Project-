# 📌 Project Overview

Modern enterprise applications rely heavily on APIs for communication between systems. Ensuring these APIs are reliable, accurate, and performant is a critical responsibility for QA Engineers and SDETs.

This repository demonstrates **SOAP API functional testing** using **Postman** and **Newman**, showcasing a structured API testing workflow including request validation, response verification, automated execution, and professional reporting.

The project uses the publicly available **Number Conversion SOAP Web Service** to validate business functionality by converting numeric values into their corresponding English word representations.

# 🚀 Running the Project

## 1️⃣ Clone Repository

```bash
git clone https://github.com/ArpitChoubey/SOAP-API-Project.git
```

---

## 2️⃣ Import Collection

Open **Postman**

Import

```
SOAP Project.postman_collection.json
```

---

## 3️⃣ Execute Collection

Run directly from Postman Collection Runner.

OR

Run using Newman

```bash
newman run "SOAP Project.postman_collection.json"
```

---

## 4️⃣ Generate HTML Report

```bash
newman run "SOAP Project.postman_collection.json" \
-r cli,html
```
