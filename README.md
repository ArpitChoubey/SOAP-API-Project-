# 🔢 Number Conversion API Testing Project

## 📌 Project Summary

This project showcases API testing of a SOAP-based Number Conversion web service using Postman and Newman. The primary objective is to validate the functionality of converting numeric values into their corresponding word representations while demonstrating structured API test execution and automated reporting.

The project highlights practical API testing skills, request validation, response verification, test execution automation, and report generation—key competencies expected from QA Engineers, Test Analysts, and SDET professionals.

---

## 🎯 Project Objectives

* Validate Number-to-Words conversion functionality through SOAP API requests.
* Perform request and response verification using Postman.
* Automate collection execution using Newman.
* Generate professional execution reports for test result analysis.
* Demonstrate API testing best practices and test automation workflows.

---

## 🌐 API Details

**Web Service:** Number Conversion SOAP Service

**Base Endpoint:**
https://www.dataaccess.com/webservicesserver/numberconversion.wso

**Operation Tested:**
`NumberToWords`

### Sample Scenario

Input: `12345`

Expected Output:
"Twelve Thousand Three Hundred Forty Five"
